## Sarrera

Ezertan hasi aurretik, gure taldeak izango dituen zereginak zein izango diren eta lana nola antolatuko dugun jakitea ezinbestekoa dugu lanean ondo aritzeko. Horretarako, **GitHub** tresna erabili dugu. Honetaz aparte, ebaluazio honetan zehar digitalizazioaren hainbat kontzeptu ezberdin ere landu ditugu (Digitalizazioa, IT eta OT teknologiak, TGD-ak, cloud computing…)

### 1. GitHub

**GitHub** hodeian oinarritutako plataforma bat da, software-proiektuak eta dokumentazioa kudeatzeko, gordetzeko eta elkarlanean garatzeko erabiltzen dena. GitHub bertsio-kontrolerako sisteman oinarritzen da.
Proiektu honetan zehazki honako helburu hauetarako erabiliko dugu:

* **Bertsio-kontrola (Git)**: Fitxategietan eta dokumentazioan egindako aldaketa guztien jarraipena egiteko eta edozein unetan atzera egiteko segurtasuna izateko.
* **Proiektuaren Kudeaketa (GitHub Projects)**: Planifikazioa digitalizatzeko, zereginak banatzeko eta eguneroko jarraipena ikusteko.
* **Dokumentazioa Argitaratzea (GitHub Pages)**: Proiektuaren garapen tekniko osoa Markdown bidez dokumentatzeko eta web formatuan modu atzigarrian publikatzeko.

Aipatutako helburu hauek aurrera eraman ahal izateko, GitHub plataforman Biltegi (Repositorio) bat sortu dugu. Hau sortzeko arrazoiak honako hauek izan dira:

* **Dokumentazioa eta webgunea argitaratzeko**: Erronkaren emaitza guztiak Markdown bidez dokumentatu eta GitHub Pages erabiliz webgune estatiko gisa denok ikusteko moduan jartzeko.
* **Planifikazioaren jarraipena egiteko**: Zereginak, epeak eta eguneroko lanak GitHub Projects bidez antolatu eta irakasleek bertarako atzipena zuzena izan dezaten.
* **Talde-lana eta bertsio-kontrola**: Taldekide guztiek fitxategi berberetan modu koordinatuan eta seguruan lan egiteko, aldaketa bakoitzaren erregistroa eta historian zeharreko segurtasuna bermatzeko.

### 1.1 Nola sortu dugu Biltegia? (Jarraitutako pausoak)

* **GitHub-en sartu**: Gure erabiltzaile-kontuarekin plataforman saioa hasi.
* **Biltegi berria sortu**:
    * *New repository* aukeran sakatu eta proiektuarentzat izen egoki bat jarri dugu.
    * Irisgarritasuna **Public** (publikoa) moduan konfiguratu dugu, irakasleek lanak arazorik gabe ikusi eta ebaluatu ditzaten.
* **Lotura eta Erabilera**: Guztiok batera lan egin ahal izateko, sortutako Biltegi onetara taldeko kide guztiak batu gara.
* **GitHub Desktop**: Taldeko kide bakoitzak, GitHub Desktop softwarea instalatu dugu. Honek gure proiektua hodeiarekin (nube) sinkronizatuta edukitzen uzten digu eta horrela, proiektuan zehar egiten ditugun lan eta aldaketa guztiak, guztion gailuetan eguneratuta izatea ahalbidetzen digu.
* **Gure lana erakutsi**: Amaitzeko, GitHub plataforman egindako dokumentazioa publikoari erakutsi ahal izateko, plataformak berak ematen digun aukera bat aprobetxatu dugu.  Gure dokumentazioa, Web-horri gisa argitaratu dugu. Aukera hau, Biltegiaren konfiguraziora sartu eta **GitHub Pages** atalean jarri dugu martxan.

### 1.2 Lanaren planifikazioa:

Egin beharrekoa zein den eta nora heldu nahi den proiektuarekin guztiok garbi eduki ahal izateko, Erronka osoan zehar egin beharreko ataza guztiak identifikatu eta zerrendatu ditugu. Horretarako, eginbehar guztien denboralizazio zehatza egin dugu modulu bakoitzerako. Moduluen arteko menpekotasunak kontuan hartuta (adibidez, sareko kableak eta pasahitzen kalkuluak, diskoen konfigurazioa edo datu-basearen diseinua), GANTT diagrama bat erabili dugu denbora-lerroan lanak modu grafiko eta ordenatuan banatzeko eta asteko helburuak betetzen direla ziurtatzeko. Hau ere, GitHub plataforman egin dugu. Hau sortzeko honako pauso hauek jarraitu ditugu:

* Aurreko atalean sortu dugun Biltegi barruan, **Proiektu** berri bat sortu dugu. Oraingoan ere, Irisgarritasuna **Public** (publikoa) moduan konfiguratu dugu, irakasleek arazorik gabe ikus dezaten.
* Gannt Diagrama aukeratu dugu.
* 3 zutabe sortu ditugu (Egitekoak, egiten eta Egindakoak).
* Planifikatutako zeregin bakoitza, diagraman sartu dugu, bakoitza dagokion zatian. Hauek bakoitzak behar duen denbora eta zein modulutara lotuta dagoen jarri diogu etiketa bidez.

Guzti honi esker, bi aste iraungo duen erronka hau guztiz planifikatua utzi dugu eta modu txukun eta egoki batean lan egiteko modua ahalbidetu dugu.

### 2 Digitalizazioa, IT eta OT teknologiak, Cloud Computing eta Teknologia Gaitzaile Digitalak (TGD)

Erronkan zehar, digitalizazioko atalean, oso garrantzitsuak diren hainbat atal ere jorratu ditugu aurreko ataletan aipatu ditugunetaz aparte: digitalizazioaren oinarriak, IT eta OT teknologiak, hodeiko sistemak eta Teknologia Gaitzaile Digitalak (TGD). Atal honetan, gai hauen inguruko azalpenak emango ditugu

### 2.1 Digitalizazioa

Digitalizazioak prozesu, produktu eta zerbitzu tradizionalak teknologia digitalaren bidez eraldatzeari egiten dio erreferentzia, informazio analogikoa digital bihurtuz. Honek ez du soilik zereginak informatizatzea bilatzen, enpresan nola lan egiten den eta erabakiak nola hartzen diren birdefinitzea ere bai.

**Zergatik eta nola egiten da?**

* Eraginkortasuna eta zehaztasuna handitzeko, akatsak saihestuz.
* Bezeroekin berehala komunikatzeko eta telelana ahalbidetzeko.
* Negozio-aukera berriak sortzeko.

Tresna nagusiak: dokumentu digitalak, prozesu automatizatuak, komunikazio elektronikoa, hodeiko biltegiratzea, merkataritza elektronikoa eta datuen analisia.

**Aldaketak enpresan:** Lanpostu errepikakorrak desagertu eta teknologia maneiatzeko profil kualifikatuagoak sortzen dira. Halaber, komunikazioa arintzen da, eta hierarkiak murriztuz antolaketa horizontalagoak bultzatzen dira, denbora errealeko datuetan oinarritutako erabakiak hartzeko.

### 2.2 IT eta OT teknologiak

Enpresa-ingurune digitalean bi teknologia-talde handi bereizten dira (IT eta OT). Hauek helburu eta ikuspegi desberdinak dituzte baina erakundearen eraginkortasuna hobetzeko osatzen dira:

- **Informazioaren Teknologiak (IT)**: Datuak prozesatzera eta informazioa kudeatzera bideratutako tresna digitalak dira. Enpresaren garuna bezalakoak dira; gauzak antolatzen, beste pertsona batzuekin komunikatzen eta erabaki adimendunak hartzen laguntzen dute.

    * Teknologia motak: Softwarea, sareak, datu-baseak eta aplikazio informatikoak. 
    * Segurtasuna: Datuak eta sistemak mehatxu zibernetikoen aurka babestean datza. 
    * Bizi-zikloa: Bizi-ziklo laburragoak dituzte, eguneratze teknologiko etengabeak direla eta. 
    * Adibideak: Microsoft Azure (hodeiko plataforma) edo VMware (zerbitzari fisikoetan makina birtualak sortzekoa). 

- **Operazio Teknologiak (OT)**: Etxeko, industriako eta merkataritzako prozesu fisikoak kontrolatzera eta automatizatzera bideratutako tresna digitalak dira. Konpainiaren besoak eta hankak bezalakoak dira; fabrikazio industrialerako, garraiorako edo energia ekoizpenerako teknologia espezifikoak biltzen dituzte. 

    * Teknologia motak: Sentsoreak, kontrolagailu industrialak eta automatizazio-sistemak. 
    * Segurtasuna: Sistema industrialak eraso informatikoetatik babestean datza. 
    * Bizi-zikloa: Bizi-ziklo luzeagoetara jotzen dute, ekoizpena egonkortzeko eta ekipoen kostu handiagatik. 
    * Adibideak: SCADA (ekipoak denbora errealean monitorizatzeko kontrol-sistema) eta PLC (berariazko zereginak egiteko gailu programagarriak). 

Bi inguruneen konbergentziak edo interkonexioak enpresaren kudeaketa eraginkorragoa ahalbidetzen du. Ekoizpenaren denbora errealeko monitorizazioak (OT) arazoak goiz detektatzea eta kalitate-estandarrak (IT) hobetzea ahalbidetzen du, mantentze prediktiboa planifikatuz eta segurtasun integrala bermatuz.

### 2.3 Cloudean oinarritutako sistemak (Cloud Computing)

**Hodeia** internet bidez erabilgarri dauden konputazio-baliabideak eta urruneko zerbitzariak dira, eta horiei esker ez da beharrezkoa biltegiratze fisiko handirik norberaren ordenagailuan izatea.

Baliabide hauek erabiltzeak, honako **Abantailak** ekartzen ditu enpresentzat: Azpiegiturak eskalatzea (behar denaren arabera kontratatzea), akatsen osteko errekuperazioa segurtasun-kopien bidez, eta edonondik zein edozein gailutatik datuak segurtasunez atzitzea.

Datuak hodeian edukitzeak ordea, izatez, baditu bere desabantaiak. Askotan latentzia (tiempo de respuesta) arazoak egotea posible da. Latentzia sistema batek eskaera bat jaso ondoren, eskaera horri erantzuteko behar duen denborari edo atzerapenari dagokio. Hala ere, latentzia hau murrizteko teknologia osagarriak ere garatu dira:

* **Mist Computing (Gailuan bertan):** Datuak biltzen diren gailu berean prozesatzen dira, beste inora ezer bidali gabe.

*Adibidea: Autoaren sentsoreak oztopo bat ikusi eta, milisegundo batean, autoaren ordenagailuak berak (beste inori galdetu gabe) frenoa aktibatzen duenean.*

* **Edge Computing (Gailutik oso hurbil dagoen beste gailu batean):** Prozesamendua ez da gailuan bertan egiten, bere oso gertu dagoen beste gailu batean baizik.

*Adibidea: Autoaren kamerak irudiak hartu, eta autoaren barruan dagoen ordenagailu edo kaxa espezifiko batean (kameraren ondoan bertan) aztertzen direnean, internetera konektatu behar izan gabe.*

* **Fog Computing (Inguruko zerbitzari lokal batean):** Tarteko geruza bat da. Datuak ez dira autoan bertan prozesatzen, baizik eta inguruko zerbitzari lokal batera bidaltzen dira.

*Adibidea: Enpresa bateko banaketa-kamioi guztiek beren datuak bidaltzen dituztenean, enpresaren bulegoan bertan dagoen zerbitzari lokalera, interneteko hodei nagusira igo behar izan gabe.*


Hona hemen hodei ereduen eta zerbitzu ereduen (IaaS, PaaS, SaaS) azalpen garatu eta sakonagoa, azterketarako ezin hobea:

#### 2.3.1 Hodeia ezartzeko ereduak (Mailak)

Hodei bat nola antolatzen den eta nork kudeatzen duen kontuan hartuta, hiru eredu nagusi bereizten dira:

* **Hodei publikoak:** Zerbitzu-hornitzaileek enpresatik kanpoko hodeian kudeatzen dituzte eta edonoren eskura egoten dira. Enpresek baliabide horiek eskariaren arabera eskuratzen dituzte, beren beharren arabera.
* **Hodei pribatuak:** Erakunde edo enpresa bakar baten jabetzakoak dira, eta beren datu-zentro propioak erabiltzen dituzte. Horrek datuen gaineko kontrol eta segurtasun maila handiagoa ematen du.
* **Hodei hibridoak:** Hodei publikoaren eta pribatuaren ereduak konbinatzen dituzte. Horri esker, enpresek hodei publikoko abantailak eta zerbitzuak balia ditzakete, baina datu sentikorrenak babesteko segurtasun-funtzioak hodei pribatuen arkitekturetan mantentzen dituzte.

#### 2.3.2 Hodeiko zerbitzu ereduak (Kontenedoreak eta mailak)

Hodeiko konputazioak ekipamendu eta zerbitzu maila desberdinak eskaintzen ditu (hauek kontenedore gisa diraezagunak), aplikazioak garatu eta exekutatzeko moduaren arabera. Hiru eredu nagusi daude:

* **IaaS (Azpiegitura zerbitzu gisa / *Infrastructure as a Service*):** Azpiegitura informatikoko oinarrizko baliabideetarako sarbidea eskaintzen du: konputazioa, biltegiratzea, sareak eta birtualizazioa.

*Adibidea: Ordenagailu baten oinarrizko osagai guztiak hodeian alokatzea bezala da (prozesatzeko ahalmena, gauzak gordetzeko espazioa, konexioa). Erabiltzaileak kontrol handia du baliabide horien gainean, bere ordenagailu fisikoa balitz bezala.(Google Compute Engine, Azure Virtual Machine edo Amazon EC2)*

* **PaaS (Plataforma zerbitzu gisa / *Platform as a Service*):** Hodeian aplikazioak garatu, probatu eta sortzeko beharrezkoak diren hardware- eta software-baliabideak eskaintzen ditu, azpiko azpiegitura mantentzeaz arduratu behar izan gabe.

*Adibidea: Aplikazioak eraikitzeko prest dagoen ingurune edo "ordenagailu" bat alokatzea bezala da. Enpresek beren programak garatu ditzakete xehetasun teknikoetan pentsatu gabe (Google App Engine, Azure App Engine edo Salesforce).*

* **SaaS (Softwarea zerbitzu gisa / *Software as a Service*):** Erabiltzeko prest dagoen aplikazio edota software sorta zabala eskaintzen du, azpiko azpiegituraz zein softwarearen mantentze eta eguneratzeez arduratu behar izan gabe.

*Adibidea: Dena barne duen aplikazio bat edo programa bat zuzenean erabiltzea da, akats teknikoak nola konpondu edo nola eguneratzen den kezkatu gabe (Amazon Web Services, Google Workspace edo Microsoft 365).*

### 2.4 Teknologia Gaitzaile Digitalak (TGD)

Teknologia Gaitzaile Digitalak eraldaketa digitala ahalbidetzen duten eta sektore industrial nahiz profesional desberdinetan sakoneko aldaketak eta negozio-eredu berriak sortzen laguntzen duten teknologia aurreratuak dira. 

#### 2.4.1 TGD nagusiak eta ezaugarriak

Teknologia hauek ezaugarri komunak dituzte (moldakortasuna, automatizazioa, interkonexioa, analitika aurreratua, segurtasuna, eskalagarritasuna, pertsonalizazioa, aurrezpena eta berrikuntza). Honako hauek dira adibide nagusiak:

* IoT (Gauzen Internet): Gailu eta objektu fisikoak Internetera konektatzea, datuak denbora errealean biltzeko eta prozesuak automatizatzeko. 
* Adimen Artifiziala (IA / AA): Makinei ikasteko, arrazoitzeko eta erabakiak hartzeko aukera ematen dieten algoritmoak. 
* Big Data eta datuen analisia: Datu-bolumen handiak biltzeko, biltegiratzeko eta aztertzeko gaitasuna, lehiarako abantaila bihurtzeko. 
* Cloud Computing: Datuak eta aplikazioak Internet bidez prozesatu eta biltegiratzea. 
* Zibersegurtasuna: Sistemak, sareak eta datuak mehatxu zibernetikoetatik babesteko teknologiak. 
* Errealitate Areagotua eta Birtuala: Esperientzia digital murgiltzaileak sortzea (ingurune errealak aberastuz edo ingurune simulatuak sortuz). 
* Blockchain: Transakzioen erregistro deszentralizatu eta segurua eskaintzen du. 
* 5G: Bosgarren belaunaldiko sareak, konektibitate azkarragoa eta fidagarriagoa emateko. 
* Robotika: Zereginak eta prozesuak automatizatzeko robotak eta prozesu errepikakorrak egiteko softwarea erabiltzea. 
* 3D inprimaketa: Hiru dimentsioko objektuen fabrikazioa (organoak, elikagaiak edo etxebizitzak sortzeraino). 
* Biometria: Ezaugarri biometrikoak erabiltzea (hatz-marka, aurpegia, ahotsa) autentifikaziorako eta segurtasunerako. 

#### 2.4.2 Ingurumen-eragina

TGDek eragin bikoitza dute ingurumenean: 

* Ondorio positiboak: Paperaren erabilera murriztea, eraginkortasun energetiko handiagoa lortzea eta telelanaren bidez joan-etorriak eta emisioak txikitzea. 
* Ondorio negatiboak: Hondakin elektronikoak sortzea (zaharkitze-ziklo azkarraren erruz), gailuen eta datu-zentroen karbono-aztarna handia, energia-kontsumo altua eta baliabide naturalak agortzea.
