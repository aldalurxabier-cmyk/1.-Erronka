## Aurkezpena

Gu SISA1-eko 4 ikasle gaituzue, **Oier Ortuzar, Iker Ortega, Iñaki De la Flor** eta **Xabier Aldalur** hain zuzen, eta lehen erronka hau egiteko taldea osatzen dugu. Ikastetxearen partetik erronka hau burutzeko hainbat baliabide jaso ondoren, erronka honen dokumentazioa aurkezteari ekingo diogu.

## Sarrera

Lehen erronka honetan enpresa baten azpiegitura informatikoa osatzeko eta digitalizazio-prozesua bultzatzeko helburuarekin, **Informazioaren digitalizazio webgunea** izeneko erronkari ekin diogu. Proiektu honetan hainbat arlo tekniko uztartuko ditugu (Sistemak, Sareak, Datu-baseak, Markatze-lengoaiak eta Digitalizazioa):

* **Sistemak**: Windows Server zerbitzaria konfiguratu, bolumenak (RAID) kudeatu eta segurtasun-politikak ezarriko ditugu.
* **Sareak**: Sareko transmisioak, pasahitzak ASCIIra igaro eta CRC-6 kalkuluak egingo ditugu, seinaleen kodifikazioa eta modulazioa marraztuz.
* **Datu-baseak**: Streaming plataforma baterako ER diagrama eta eredu erlazional normalizatua diseinatu eta inplementatuko dugu.
* **Markatze Lengoaiak**: HTML, CSS eta estilo-orrien bidez webgune estatikoa eta atzigarria sortuko dugu.
* **Digitalizazioa**: Proiektuaren planifikazioa eta jarraipen digitala bideratuko dugu, hodeiko kudeaketa-tresnak erabiliz.

Proiektu osoaren kudeaketa eta dokumentazioa **GitHub** tresnaren bidez burutuko dugu.
